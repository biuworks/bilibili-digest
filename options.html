Digest for Bilibili 设置

字幕

字幕由 B 站官方接口提供，无需配置密钥。 部分字幕（含 AI 生成字幕）仅在登录后可见， 请先在浏览器中登录 B 站账号。

显示

本节设置仅作用于当前设备的侧边栏与本页面，修改后立即生效，无需执行「保存并授权」。

AI 服务

字幕顺句、AI 概览、划词解释与笔记润色需调用大模型服务。 选择服务商后填写 API 密钥与模型名称即可，接口地址已内置； 如需使用列表外的服务，请选择「自定义」并自行填写地址与协议。 密钥仅保存于本机扩展存储，且只发送至所选服务商的接口地址。

执行「保存并授权」时，浏览器将询问是否允许本扩展访问所选服务商的域名。 这是浏览器的权限机制：扩展在安装阶段无法预知所使用的服务， 因此需在选定服务商后单独申请，且仅申请该域名。

学习资料

笔记与长期概览仅保存在当前设备，卸载扩展后将由浏览器一并清除。 导出的备份不含 API 密钥。恢复时与本机已有数据合并，相同条目以更新时间较新者为准， 本机独有的条目不会被删除。
