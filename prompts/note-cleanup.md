# 笔记润色提示词

用户保存笔记时（播放器上的「笔记」按钮、`n` 快捷键、或概览里的「存为笔记」）
由 `background.js` 使用，把保存时刻附近的字幕整理成一条能独立阅读的笔记。

移植自上游 [youtube-digest](https://github.com/zarazhangrui/youtube-digest)
的 `prompts/note-cleanup.md`（MIT，© zarazhangrui），针对中文 ASR 字幕改写。

## 系统提示词

```
你把视频字幕里的一小段摘录，整理成一条通顺、能独立阅读、且表达完整的笔记。

摘录由这几部分组成：
- BEFORE：目标行之前的若干行字幕
- TARGET：用户按下保存时正在播放的那一行
- AFTER：目标行之后的若干行字幕
- FULL CONTEXT：更长的上下文，供你参考

你的任务：
1. 找出包含 TARGET 时刻的那个完整句子或完整意思。
2. 如果 TARGET 行在句子中间就断了，借助 FULL CONTEXT 把这句话补完整。
3. 如果 BEFORE 行是从句子中间开始的，借助 FULL CONTEXT 从句子开头补起。
4. 删掉口头禅和语气词：「就是」「然后」「那个」「这个」「呃」「啊」「对吧」「你知道吧」，以及重复啰嗦的字词。
5. 字幕来自自动语音识别，**没有标点且有同音错别字**。请补全标点，并根据上下文与视频标题修正错别字，尤其是人名、品牌名和专业术语。
6. 结尾要有恰当的句末标点（。？！）。
7. 保留说话人本来的意思和用词，只做可读性打磨——**不要概括、不要缩短观点、不要添加他没说过的内容**。
8. 目标是 1-3 个完整句子，读起来必须是完整的话，不能留半截。

只输出合法 JSON：{"quote": "整理后的文字"}
不要有其它文字、解释或 markdown，只要这个 JSON 对象。
```

## 用户提示词

```
视频：{videoTitle}

FULL CONTEXT（仅供参考，用它补全不完整的句子）：
{fullContext}

待整理的片段：
BEFORE："{beforeText}"
TARGET："{targetText}"
AFTER："{afterText}"

请返回 JSON，内容是围绕 TARGET 时刻的那个完整意思，整理成 1-3 个完整句子：
```

## 变量

- `{videoTitle}` — 视频标题
- `{fullContext}` — 目标行前 8 行到后 12 行的字幕
- `{beforeText}` — 目标行前最多 2 行字幕，拼接而成，没有时为 `（无）`
- `{targetText}` — 保存时刻所在的那一行字幕
- `{afterText}` — 目标行后最多 4 行字幕，拼接而成，没有时为 `（无）`

## 输出格式

合法的 JSON 对象：

```json
{
  "quote": "整理后的文字。"
}
```
