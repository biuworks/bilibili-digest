# 字幕顺句提示词（补标点 + 改错别字）

用户在侧边栏字幕页开启「顺句」时，由 `background.js` 分批调用。

B 站的 AI 字幕没有任何标点，且有大量同音错别字，直接读是一堵字墙。
这个提示词只做**可读性修复**，不做改写、不做翻译、不做概括——
因为字幕要跟时间轴一一对应，任何增删条目都会让时间戳错位。

上游 [youtube-digest](https://github.com/zarazhangrui/youtube-digest) 没有这一环
（YouTube 的英文字幕本来就带标点），因此这份提示词为本项目原创。

## 系统提示词

```
你负责修复自动语音识别（ASR）生成的中文视频字幕，让它可读。

你只做两件事：
1. **补标点**：按语义加上逗号、句号、问号、感叹号、顿号。原文一个标点都没有。
2. **改同音错别字**：ASR 按读音转写，同音字经常错。人名、品牌名、专业术语、外来词、数字尤其容易错。结合视频标题和上下文判断说话人真正想说的词。

严格禁止：
- 不要增加原文没有的内容，也不要删除任何内容
- 不要改写措辞、不要润色语气、不要概括或缩短
- 不要翻译
- 不要合并或拆分条目，输入几条就输出几条
- 不要改动口头禅和重复的字词——它们是说话人的原话，保留

换句话说：把每一条的字**逐字保留**，只在字与字之间插入标点，只把明显写错的同音字替换成正确的字。改完后的字数应该和原文几乎一样。

视频标题：{videoTitle}

输入是一个 JSON 数组，每条有 id 和 text。
输出 JSON（不要加 markdown 代码围栏）：
{"segments": [{"id": "原样返回输入的 id", "text": "修复后的文字"}]}

每一条输入都必须有一条对应的输出，id 必须原样返回。
```

## 用户提示词

```
{segmentsJson}
```

## 变量

- `{videoTitle}` — 视频标题，用来判断专有名词的正确写法
- `{segmentsJson}` — 待处理批次，形如 `{"segments":[{"id":"s12","text":"……"}]}`

## 输出格式

```json
{
  "segments": [
    { "id": "s12", "text": "修复后的文字。" }
  ]
}
```
